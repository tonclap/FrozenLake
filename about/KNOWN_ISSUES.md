# Known Issues — FrozenLake

Формат: **описание** — условие воспроизведения — обходной путь / статус.

- **Модели с датой 2025-03 несовместимы с текущим наблюдением** — коммит `75a343f`
  заменил канал 2 наблюдения с манхэттенского расстояния на BFS-дистанцию, а веса
  под старую семантику остались — под текущим кодом они давали 77–94% вместо чисел
  в своих именах. 09.08.2026 из этой партии (11 файлов) удалены все, кроме лучшей
  под текущим кодом — `models/09979_exp_2_ep30000.pth` (93.99%), оставлена как
  историческая точка вместе с парным логом `runs/09979_30000`. Имена файлов
  кодируют исторический результат, а не воспроизводимый; сравнивать модели только
  прогоном `fast_eval.py`.
- **`results/results.txt` описывает прежнюю постановку** — числа оттуда (в том числе
  99.79%) получены с манхэттенским наблюдением и не воспроизводятся текущим кодом.
- **Обучение через `experiment.py`/`trainer.py` не сходится к 100%** — сэмплирование
  карт по вероятности льда `p` не покрывает карты с высокой плотностью дыр, на
  которых и остаются провалы — для добивания хвоста использовать
  `curriculum_trainer.py`, он берёт карты из полного перечисления.
- **Шейпинг в `trainer.py` считается по манхэттенскому расстоянию** — хотя канал 2
  наблюдения уже содержит BFS-дистанцию — на картах с единственным узким проходом
  геометрическая «близость» вводит в заблуждение; в `curriculum_trainer.py` есть
  `--shaping bfs`, но по умолчанию при дообучении берётся `manhattan`, чтобы
  совпадать с функцией награды, под которую обучен чекпоинт.
- **Смена функции награды при дообучении обрушивает политику** — Q-значения кодируют
  возвраты конкретной функции награды, поэтому дообучение с другими `GAMMA`,
  `N_STEP` или коэффициентами шейпинга роняло 99.53% до 78% за 300 эпизодов
  (а прежний `finetune.py` — до 73%, см. `results/finetune.log`) — дообучать только
  с флагом `--use-ckpt-config`, наследующим гиперпараметры чекпоинта.
- **`gym` 0.26.2 несовместим с NumPy 2.x** — использует удалённый псевдоним
  `np.bool8` — окружение пинит `numpy<2` (см. `requirements.txt`).
